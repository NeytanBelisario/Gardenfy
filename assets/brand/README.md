# Marca do Gardenfy

- `gardenfy-logo-source.png`: logo original, 1254 × 1254, fundo creme `#FDF9F3`. Fonte para gerar os demais arquivos.
- `gardenfy-logo.png`: logo com nome reduzida para 600 px, usada no README.
- `gardenfy-mark.png`: só o símbolo das folhas, recortado do fundo com transparência. Usado no menu lateral do app.

Ícones gerados a partir do símbolo, em `assets/images`:

| Arquivo | Uso | Composição |
| :-- | :-- | :-- |
| `icon.png` | Ícone iOS e padrão | 1024 px, símbolo com 62% da altura sobre `#FDF9F3` |
| `android-icon-foreground.png` | Ícone adaptativo Android | 1024 px transparente, símbolo com 44% da altura, dentro da zona segura |
| `android-icon-background.png` | Ícone adaptativo Android | 1024 px em `#FDF9F3` |
| `android-icon-monochrome.png` | Ícone temático do Android 13+ | Mesmo layout do foreground, em branco |
| `splash-icon.png` | Splash Android | 512 px transparente, exibido com 200 dp sobre `#FDF9F3` |
| `favicon.png` | Web | 48 px transparente |

As nervuras do símbolo são transparentes. Ele foi pensado para fundos claros; sobre fundos escuros, as nervuras se perdem.
